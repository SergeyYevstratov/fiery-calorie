# FIERY CALORIE

Оновлена версія навчального проєкту на Vue 3 + Vite.

## Що змінено
- прибрано окремий екран входу;
- додано сторінку **Особистий кабінет**;
- додано сторінку **Історія розрахунків**;
- збереження профілю, параметрів та історії через LocalStorage;
- покращено хедер, футер і мобільне меню;
- шлях до логотипу зроблено коректним для локального запуску і GitHub Pages;
- очищено архів від зайвих папок `.git` і `node_modules`.

## Запуск
```bash
npm install
npm run dev
```

## Збірка
```bash
npm run build
```
